# SocietyAPP UI

React Native mobile application for the SocietyAPP resident-to-resident help network.

## Planned stack
- React Native 0.87
- TypeScript
- Android development with Android Studio
- FastAPI backend
- PostgreSQL / Supabase during development

## Development
The native React Native project should be generated locally with the React Native Community CLI, then committed to this repository.

Command:

    npx @react-native-community/cli@latest init SocietyApp

Then run:

    npx react-native start
    npx react-native run-android
